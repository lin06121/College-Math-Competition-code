# 问题 2 与问题 4-2 代码（提供版实现）

本目录是**生成 `result2.xlsx` 与 `result4-2.xlsx` 的代码**（独立实现）。问题一、问题三、
问题四之三的代码与结果不在此目录，见上一级 `代码\Python\`（原实现）。

## 一、方法要点

| 环节 | 做法 |
|---|---|
| 负载预测 | 最近 **4 个同类日**实测均值（周五、周六为一类，其余五天为一类） |
| 光伏预测 | 最近 **4 个连续日**实测均值 —— **问题 2 不使用附件 3 的光伏预报**（题目问题 2 只给附件 1、附件 2 数据） |
| 安全裕度 | 净负荷残差的 q 分位（报童模型），q\* 的理论临界比 4p/(4p+p)=0.8，在 2025 年 1 月外样本标定确认 |
| 日前计划 | 单日 MILP（`scipy.optimize.milp`）：充放电互斥 0-1 变量、SOC ∈ [1200, 10800] kWh、充放电 ≤ 5000 kW、单程效率 90%、0:00 储电量 6000 kWh 起逐日滚动 |
| 实时结算 | 逐时段**因果**规则，只用当前实测净负荷与当前储电量：缺口先放电兜底、仍不足按 **5 倍电价**紧急购电；富余先充电、仍吸纳不下则弃光 |
| 问题 4-2 | 计划价改为**因果电价预报**（近 14 天同时段均值，`forecast_q4.py`），结算价用附件 4 实际电价 |

与问题 2 原实现的差别：**预测依据改为纯历史（不用附件 3）**，报童分位由 0.7 改为按理论
临界比标定的 **0.8**；其余（计划模型、因果结算规则）同构。

## 二、运行方式

```bash
# 0) 依赖：numpy / pandas / scipy / openpyxl
# 1) 预处理：附件 1-4 -> data/processed/*.csv 与 matrices.npz
PYTHONUTF8=1 python preprocess.py
# 2) 问题 2：1 月标定 q* + 全年滚动求解 -> result2.xlsx（约 16 s）
PYTHONUTF8=1 python run_q2.py
# 3) 问题 4-2：波动电价下重算问题 2 -> result4-2.xlsx（约 30 s）
PYTHONUTF8=1 python run_q4_2.py
```

`run_q4_2.py` 是把原仓库 `run_q4.py` 中 Q4-2 那一段单独抽出的一键入口，调用的求解与校验
函数与原始脚本完全一致（`solver_q2.solve_problem4_2` + `format_result_q2` 三表输出）。

**附件路径**：`config.py` 中 `ATTACHMENT_DIR` 会依次尝试
`<ROOT>/problem/C题/附件`、`<ROOT>/附件`、`<ROOT>/../附件`、`<ROOT>/../../附件`，
取第一个存在的目录；附件 5 的结果模板须位于 `ATTACHMENT_DIR/附件5/`。
（原实现写死第一种；此处只增强路径定位，**未改动任何计算逻辑**。）
