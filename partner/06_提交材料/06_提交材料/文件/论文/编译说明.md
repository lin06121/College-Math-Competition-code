# 论文编译说明

本目录是论文的**工作副本**（模板版）。若要在**在线编译器**上编辑，请直接用
`08_Overleaf\` 目录：里面只有一个 `main.tex`（全部章节内联）＋ 11 张插图，**不需要**
`cumcmthesis.cls` / `cumcm2026.sty` / `fonts\` 等任何附带文件。

## 一、Overleaf 在线编译（推荐）

**方式 A（最省事）**：把 `08_Overleaf\` 整个目录上传到 Overleaf（New Project → Upload Project），
主文件设为 `main.tex`，编译器选 **XeLaTeX**（Menu → Compiler → XeLaTeX），编译即可（38 页）。
该目录**只有一个 `main.tex` 与 11 张插图**；导言区使用 `ctexart` + `fontset=fandol`，
与 Overleaf 自带字体完全匹配，无需配置字体，也不需要 `cumcmthesis.cls` / `cumcm2026.sty`。
（本机 XeLaTeX 试编译结果见同级目录 `main_overleaf_单文件版试编译.pdf`。）

**方式 B（模板版）**：把本目录整体上传，主文件 `main.tex`，同样用 **XeLaTeX** 编译。
本目录的字体块用 `\IfFileExists{fonts/times.ttf}` 做了自适应：本机按字体文件路径加载；
Overleaf 无 `fonts/` 时自动跳过，沿用 `cumcmthesis.cls` 的默认字体名。

## 二、本地编译（本工作区已装好 XeLaTeX）

TeX Live 2026 已安装在工作区：`00_环境\texlive`。**注意**：TeX 引擎对中文路径支持不佳，
故由脚本在“当前会话的 ASCII 临时目录”内编译，随后自动把 PDF 拷回本目录，
并同时试编译 `08_Overleaf\main.tex`（输出 `08_Overleaf\main_preview.pdf`）：

```powershell
pwsh -NoProfile -File "00_环境\tex\build_paper.ps1"
```

## 三、中文字体与缺字问题的处理（2026-09 修订）

沙箱环境下的 TeX 无法按**字体名**查找系统字体，最初出现“部分中文/符号显示为空白”。
已做三项修复，最终编译日志中 **Missing character = 0**（逐字校验，无任何缺字）：

| 问题 | 现象 | 修复 |
|---|---|---|
| 中文字体族按名称查找失败 | 标题、楷体等中文缺字 | `\PassOptionsToPackage{fontset=none}{ctex}` + 在 `main.tex` 中把宋/黑/楷/仿宋**按字体文件路径**定义（`fonts/` 目录随论文打包） |
| 圈码 ①—⑤ 被排入西文字体 | 摘要与正文圈码显示为空白（日志：`Missing character: There is no ① (U+2460) in font times.ttf`） | `\xeCJKDeclareCharClass{CJK}{"2460 -> "24FF, "3001 -> "303F, "FF01 -> "FF5E}`，圈码与中文标点改按中文字体排版 |
| 数学正体缺字 | `\min/\max/\mathrm{Cost}` 丢字 | `\setmathrm/\setmathsf/\setmathtt` 同样按文件路径指定；`\min/\max` 改用文本字体实现 |

> 日志中若出现 3 条 `Package fontspec Error: The font "Times New Roman"/"Arial" cannot be found`，
> 是模板类 `cumcmthesis.cls` 自身按字体名请求所致，**非致命**：其字体已被路径字体覆盖，
> 不影响版面与显示，正常 TeX 环境下该提示自动消失。
>
> `08_Overleaf\main.tex` 不含字体块（用 `fontset=fandol`），因此不会出现上述任何提示。

## 四、目录结构

```
05_论文与结果\论文\
├─ main.tex                  主文件（摘要、参考文献、AI 声明、附录装配）
├─ cumcmthesis.cls           2026 国赛模板类文件
├─ cumcm2026.sty             模板附加样式（含 \CumcmAIUsed）
├─ sections\                 分节源码（sec1…sec10 + appendix）
├─ figures\                  论文插图（11 张，由脚本自动生成）
├─ fonts\                    本地编译所需字体（Overleaf 可删）
├─ paper_numbers.json        论文全部关键数字（脚本自动汇总）
├─ paper_tables.json         论文表 1/2/3 数据（从结果文件反向提取，保证一致）
└─ main.pdf                  成稿 PDF（37 页）
```
