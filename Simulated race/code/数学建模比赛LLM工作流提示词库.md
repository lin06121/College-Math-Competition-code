## 0. 总纲：LLM 参与数模的边界（务必遵守）

- **核心产出必须自研**：模型、公式、目标、结论由人类主导；LLM 用于：知识检索、思路启发、代码编写与调试、绘图、文字润色、格式整理。
- **AI 声明与查重**：论文写 AI 使用声明（工具名/用途/环节/核验），不得整段照搬 LLM 正文与图片；支撑材料附 AI 详情。
- **提示词四要素**（每次发任务都带全）：
  `你是<角色>；任务是<做什么>；目标是<论文要支撑的结论>；操作流程是<分几步、每步产出什么>。`

## 2. 沙箱与 MATLAB 实跑经验（本机实测，先读）

> 本节是把"让 LLM 帮你跑 MATLAB 并产出可信结果"落地的前提。以下均为本项目实测结论。

### 2.1 环境事实（无工具箱也能做的清单）
本机 MATLAB R2024a **只有基础模块**（无统计/优化/全局优化/文本工具箱）。实测可手写替代的等价实现：

| 想用的函数（需工具箱） | 手写等价实现（实测可用） |
|---|---|
| `fitlm/regress` | 岭回归正规方程 `β=(X'X+λI)\X'y`；交叉验证选 λ |
| `fitrtree/fitrensemble` | 自写 CART（方差减少分裂）+ 装袋随机森林 |
| `poissrnd` | Knuth 拒绝采样（vectorized） |
| `randsample/datasample` | `ceil(rand(rng,k)*n)` 有放回采样 |
| `ga/particleswarm/fmincon/linprog/intlinprog` | 模拟退火、枚举、坐标下降、手写启发式（P2 赛程用 SA） |
| `kmeans/pdist2/tiedrank/corr` | k-means 手写（Lloyd）；`corrcoef`（基础函数）；距离自写 |
| 统计检验（t/F/卡方） | 手写统计量与查表（或近似 p 值） |
| `extractFileText`（PDF） | 自写 PDF 解析（ToUnicode CMap + FlateDecode 解压） |
| `webread` 网络 | 基础函数自带（自带 OpenSSL，绕过系统 schannel 故障） |

**经验①**：让 LLM 出 MATLAB 代码时，先声明"无任何工具箱"，它会自动改用手写/基础函数——否则会报 `requires Statistics and Machine Learning Toolbox`。

### 2.2 启动与沙箱（重要）
- **沙箱 IPC 限制会让 MATLAB 无法启动**（错误 5201 / "Unable to load ApplicationService client-v1"）：MATLAB 许可服务经命名管道通信。受限模式下需在**更宽权限**运行 `matlab -batch`。
- **命令行调用模板**（成功路径）：
  `matlab -batch "run('D:\ascii\code\main.m')" -WorkingDirectory <ASCII目录>`
- **中文路径陷阱**：MATLAB 对含中文路径的 `exist/readtable/run` 会失败——**代码、数据、输出全部放纯 ASCII 目录**（如 `D:\work\run1`），最后再把结果复制回中文命名的论文目录。
- **长任务**：求解/蒙特卡洛（如 2 万次模拟）放后台执行，输出与错误分开写文件（`out.txt / err.txt`），轮询日志即可；避免在同一个同步调用里死等。
- **随机种子**：所有随机（采样、SA、MC）固定种子（如 `rng 2026` / `RandStream('mt19937ar','Seed',2026)`），保证可复现。
- **文件规范**：结果 CSV 保持模板列名与顺序（UTF-8）；图导出 `exportgraphics(gcf,'f.png','Resolution',300)` 或矢量 PDF。

### 2.3 让 LLM 在沙箱跑 MATLAB 的 SOP 提示模板（四要素）

```
你是 MATLAB 编程助手，目标是在无工具箱、受限沙箱环境下产出可复现结果。
任务：<一句话>；目标是支撑论文中 <哪一节> 的 <结论>。
操作流程：
1) 输出单个 .m 脚本（只依赖基础函数，禁用任何工具箱函数；随机种子固定）；
2) 数据放 ASCII 路径 <路径>，读入并打印行列数校验；
3) 我在沙箱执行：matlab -batch "run('<脚本>')"，把 stdout/stderr 回贴给你；
4) 你根据报错给出最小修复（一次只改一处，附修改后整段函数）；
5) 收敛后输出：关键数值表 + 说明如何填入论文（公式编号/图题）。
约束：不做任何网络请求；不写中文路径；运行时间控制在 <分钟> 内；结果文件列名与模板一致。
```

## 3. 数学建模方法库（稳定型 vs 创新型）

> 用法：把题目特征贴给 LLM，让它按下面"方法选择提示词"给 2–3 条路线（**一稳一新**）。表格中 ✅=无工具箱可手写实现（见 §2.1）；🌐=推荐用 Python 生态（若允许）或移植。
> 标注：**S=稳定型**（经典、公式成熟、解释性强）；**N=创新型**（近三年前沿/组合，用于亮点与对比）。

### 3.1 预测类
| 方法 | 型 | 适用 | MATLAB 提示要点 |
|---|---|---|---|
| 灰色预测 GM(1,1) | S ✅ | 小样本、指数型 | 累加生成→一阶微分→还原；注意残差检验 |
| 多元回归 / 岭回归 / 逐步 | S ✅ | 因果预测 | 正规方程+λ；报告 R²、显著性近似 |
| 指数平滑 / 移动平均 | S ✅ | 平滑趋势 | α 网格寻优 |
| ARIMA / SARIMA | S 🌐 | 时间序列 | 差分定阶(ACF/PACF 自画)；无工具箱用 Python statsmodels |
| 马尔可夫链 | S ✅ | 状态转移 | 转移矩阵自写；极限分布求解 |
| BP 神经网络 | S ✅(自写)/🌐 | 非线性 | 反向传播自写较繁琐→建议 Python sklearn/torch |
| 灰色-回归组合 / 误差校正 | S ✅ | 提升精度 | 残差二次建模 |
| LSTM / GRU / 时序 Transformer | N 🌐 | 长序列 | Python torch；说明为什么比经典好（给出对比） |
| 机理+数据融合（灰箱/数字孪生代理） | N ✅/🌐 | 有物理约束 | 微分方程+参数辨识（fminsearch） |
| 分位数回归 / 不确定性量化 | N 🌐 | 区间预测 | 输出 90% 区间而非单点 |

### 3.2 评价类
| 方法 | 型 | 适用 | 提示要点 |
|---|---|---|---|
| 层次分析 AHP | S ✅ | 定性→定量 | 一致性检验 CR<0.1；组合权 |
| 熵权法 | S ✅ | 客观权重 | 归一化→熵→差异系数 |
| TOPSIS | S ✅ | 多方案排序 | 与 AHP/熵权结合给组合权 |
| 灰色关联度 | S ✅ | 小样本关联 | 两级最小/最大差 |
| 模糊综合评价 | S ✅ | 语言型指标 | 隶属度矩阵+权重 |
| PCA / 因子分析 | S ✅ | 降维找主因 | SVD 手写；累积贡献率≥85% |
| CRITIC / 组合赋权 | S ✅ | 主客观结合 | 相关性+对比强度 |
| 多准则+熵+TOPSIS 决策矩阵+雷达 | S ✅ | 方案报告 | 配 §绘图库雷达/哑铃 |
| 博弈组合赋权/云模型 | N ✅/🌐 | 模糊+随机 | 云滴生成，说明新颖性 |
| 基于 GNN/注意力 的复杂系统评价 | N 🌐 | 图结构数据 | 慎选，需充足数据 |

### 3.3 优化类
| 方法 | 型 | 适用 | 提示要点 |
|---|---|---|---|
| 线性/整数规划（LP/IP） | S ✅/🌐 | 资源分配、排程 | 无工具箱→自写单纯形较繁；**优先手写模拟退火/构造+局部搜索**（本项目 P2 即如此） |
| 动态规划 | S ✅ | 分段决策 | 状态/转移自写 |
| 图论：最短路/最小生成树/网络流 | S ✅ | 路径/网络 | Dijkstra/Prim 手写 |
| 指派问题（匈牙利） | S ✅ | 一对一匹配 | 手写匈牙利 ≤300 行；小规模用穷举 |
| 模拟退火 SA | S ✅ | NP 难（赛程/选址/背包） | 温度调度+可行性惩罚+多轮域更新；本项目 P2 用 SA 得可行解 |
| 遗传算法 GA / 粒子群 PSO | S ✅(自写)/🌐 | 连续/组合 | 染色体编码+锦标赛选择 |
| 蒙特卡洛模拟 | S ✅ | 概率/随机系统 | 固定种子；收敛性检验（1000/5000/20000） |
| 排队论 | S ✅ | 服务系统 | M/M/c 指标自算 |
| 差分/微分方程（机理） | S ✅ | 物理/动态 | ode45；参数辨识 fminsearch |
| 多目标优化（NSGA-II/加权和） | N ✅/🌐 | 多目标权衡 | 帕累托前沿+权重扫描 |
| 强化学习（调度/路径） | N 🌐 | 序贯决策 | 环境+Q-learning/PPO 简述 |
| 贝叶斯优化（调参/实验设计） | N ✅ | 少次昂贵评估 | EI/UCB 采集函数自写 |
| GNN+OR（组合优化学习） | N 🌐 | 大规模网络题 | 需解释相对启发式收益 |
| LLM 辅助启发式（LLM 生成候选解再局部搜索） | N 🌐 | 开放搜索 | 作为"创新"亮点，需人工核验 |

### 3.4 统计 / 数据类
| 方法 | 型 | 提示要点 |
|---|---|---|
| 假设检验（t/F/卡方） | S ✅ | 手写统计量；报告 p 值口径 |
| 方差分析 ANOVA | S ✅ | 手写 F；多重比较近似 |
| 相关/回归诊断 | S ✅ | 残差图、VIF(自写)、异方差 |
| K-means / 层次聚类 | S ✅ | Lloyd 自写；肘部/轮廓(自写) |
| 判别分析 / Logistic | S ✅/🌐 | 最大似然迭代(自写)；无工具箱建议 Python |
| 决策树/随机森林/GBDT | S/N ✅(树自写)/🌐 | 本项目 P1 已手写 CART+RF |
| SHAP / 可解释性 | N 🌐 | 给特征贡献图（论文亮点） |
| 因果推断（DAG/双重差分） | N 🌐 | 需题目有自然实验语境 |

### 3.5 方法选择提示词（一稳一新，附理由）

```
你是建模方法顾问。题目：<粘贴题目关键特征：数据类型/规模/目标/约束>。
请给出两条建模路线（不要展开实现）：
1) 稳定型：经典方法 + 具体子方法 + 为何适合（数据/结构依据）；
2) 创新型：近三年较前沿或组合方法 + 数据可行性 + 相对稳定型的增益点；
并各给出 1 个"可被审稿质疑的风险"及规避办法。
输出为两张对照表：方法 / 型(S/N) / 关键公式或算法 / 工具箱依赖 / 预期产图。
```

## 5. 可视化与报告生成（联动已有工具文档）

- **图表**：用《学术绘图图表库与LLM绘图提示模板.md》——每问先按 §4 场景表定图，套 §8/§9 提示词，风格按 §7 配色；每图**结论式图题 + 图注（口径/n）**；先易后难留出时间。
- **表**：三线表、标题在表上方、正文先引用后出现；数值格式统一。
- **报告章节 SOP**（可让 LLM 生成分节大纲+各节要写的图/表清单）：
  摘要(≤1页, 结论前置) → 问题重述/分析(首图门面) → 假设/符号(两栏表) → 模型建立与求解(公式→算法→结果图/表) → 检验(收敛/灵敏度/CV) → 评价 → AI声明 → 参考文献 → 附录(代码清单)
- **敏感性/检验节**：固定给 LLM 的三种必做图：收敛曲线、CV/误差对比、参数灵敏度（多线或热力）。

```

Step5 报告：输出可粘贴的<摘要/结论/敏感性>中文段落与图表清单。
约束：只用基础MATLAB函数；不联网；不写中文路径；尊重AI规范(声明用途、不整段照搬)。
```
