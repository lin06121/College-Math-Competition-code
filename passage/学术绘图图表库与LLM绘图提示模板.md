## 1. 核心设计原则（先读）

给 LLM 提示前，先让自己（和让 LLM）遵守这些原则——它们是"创新但不出错"的底线：

1. **图服务于论点，不是装饰**：一张图只讲 1 个核心结论；先写图题结论，再配图。
2. **数据墨水比（Data-Ink Ratio, Tufte）**：删掉网格线噪音、3D 伪立体、过度渐变、装饰性阴影；图表元素即数据元素。
3. **自明性（Self-evidence）**：读者 10 秒内看懂坐标含义与对比结论；轴标签、单位、图例、显著性标注缺一不可。
4. **诚实性**：不截断坐标轴误导、不用不等距比例、不隐藏误差；标注样本量 n。
5. **可复现**：同一数据只产生一份权威 CSV/`.mat`，代码 + 种子固定；图导出矢量格式（PDF/SVG）优先，位图≥300 dpi。
6. **色盲友好**：默认使用 Okabe-Ito / Colorblind-safe 色板，而非 rainbow。
7. **一致性**：同一论文内相同含义用同色同形；字号、线宽、风格统一。
8. **图题结论化**：数学建模论文插图下标注"图1 xxx趋势对比（说明：……）"，正文引用图号。

## 2. 图表速查矩阵（选图入口）

| 我想表达…… | 首选图 | 备选 / 进阶 | 慎用 |
|---|---|---|---|
| A 比 B 大多少（单指标分类比较） | 柱状图 | 棒棒糖图、哑铃图、华夫饼图 | 3D 柱状图 |
| 多指标多方案横向对比 | 分组柱状图 / 热力图 | 雷达图（≤6维）、条形竞速 | 堆积柱（<6类时） |
| 数值分布长什么样 | 直方图 / KDE | 小提琴图、蜂群图、箱线图、ECDF | 饼图 |
| 两组/多组分布对比 | 箱线图 + 抖动散点 | 雨云图（Raincloud）、小提琴图 | 只画平均值柱 |
| 各部分占比 | 堆叠柱 / 100%堆积柱 | 旭日图、矩形树图、南丁格尔玫瑰图 | 饼图（>5类） |
| 两变量关系（散点） | 散点图 + 回归线 | 六边形分箱、边际直方图散点、相关热图 | 气泡图（除非有第3维含义） |
| 多变量相关结构 | 相关矩阵热图 | 聚类热图、PCA 双标图 | 双轴折线（不同量纲） |

| 某事件在时间轴上的安排 | 甘特图 | 时间线图、日历热图 | 复杂网络图 |

| 误差与不确定性 | 误差棒 / 置信带 | 密度叠加、误差椭圆 | 不标误差的均值柱 |
| 收敛过程 / 算法迭代 | 收敛曲线（对数轴） | 动画帧、阶段标注 | —— |
| 方案优劣多指标总览 | 归一化雷达图 | 平行坐标、甘特+热力组合 | —— |
| 双量纲/多视角同图 | 双轴图（慎用） | 双面板小倍数、F1–F13 融合模板 | 未标单位的双轴 |

## 3. 图表类型大辞典

> 每条目格式：**名称（中/英）** → 用途 → 数据形态 → 关键参数/变体 → 提示词要点 → 避坑。
> 参照权威目录：[FT Visual Vocabulary](https://github.com/Financial-Times/chart-doctor/blob/main/visual-vocabulary/README.md)、[Data-to-Viz](https://www.data-to-viz.com/)、UCLA/FSU 选图指南、Claus Wilke《Fundamentals of Data Visualization》。

### 3.1 比较类（Comparison）

1. **柱状图 Bar Chart** — 类别间单指标比较。
   - 变体：分组柱状（Grouped）、堆叠柱（Stacked）、100%堆叠、双向柱（Pyramid/蝴蝶图）、背离柱（Diverging）。
   - 提示要点：`x=类别, y=数值`, 数值标签保留 1–2 位有效数字；类别>10 换横向；按数值排序。
   - 避坑：y 轴不从 0 起时需明示断轴；堆叠柱不用于跨组比较个别分块。

2. **棒棒糖图 Lollipop Chart** — 柱状图去冗余的极简版，突出排序与端点值。
   - 提示要点：`hlines + scatter`；适合展示排名、Top-N。

3. **哑铃图 Dumbbell Chart** — 展示同一对象在两个时点/两种方案下的变化量。
   - 用途：前后对比、A/B 方案差、两年变化；中间可用线段+端点圆点，可标注差值。
   - 数学建模应用：静态 vs 动态方案指标变化、优化前后对比。

4. **华夫饼图 Waffle Chart** — 以 10×10 或 10×N 小方块呈现占比（每格=1%/1单位）。
   - 优点：构成类的"诚实饼图"，适合单点占比宣传图。
   - 避坑：不适合精细数值比较。

5. **雷达图 Radar/Spider Chart** — 多指标单/多对象轮廓对比（每轴一个标准化指标，0–1 或 0–100）。
   - 适用：方案多准则评估（如赛程 8 指标、模型对比）。
   - 变体：带面积填充、多对象叠放、缺口蜘蛛图。
   - 避坑：≤6 维最清晰；不同量纲必须先归一化；面积大小≠优劣。
   - 数学建模应用：**问题二 8 维指标方案对比、多模型综合能力画像**。

6. **条形竞速/排名图 Bar Race** — 随时间演化的动态排名（动画）。

### 3.2 分布类（Distribution）

7. **直方图 Histogram** — bin 数选择（Freedman-Diaconis 等）影响形状；叠加 KDE 曲线。
8. **箱线图 Box Plot** — 五数概括 + 离群点；适合组间分布对比。
   - 变体：带缺口（Notched，中位数置信区间）、斧头图（字母标识显著组）。
   - 提示要点：叠加 `swarm/strip` 或半小提琴更佳。
9. **小提琴图 Violin Plot** — KDE 形状 + 箱线内核；比箱线更能展示多峰。
10. **蜂群图 Swarm/Strip/Jitter Plot** — 每个样本一个点；防重叠用 `beeswarm` 或随机抖动（固定种子）。
11. **雨云图 Raincloud Plot** — 现代替代箱线：左半小提琴 + 散点雨滴 + 右箱线，可并列多组。
    - 是近年"统计学论文里的网红图"，数学建模中使用有明显创新感且信息量大。
12. **ECDF（经验累积分布）图** — 不做 bin 假设，直接画累积比例曲线；比较两组分布是否随机占优（如是否 stochastically larger）。
13. **密度图/山脊线图 Ridge Plot** — 多条 KDE 纵向堆叠；适合多组分布随参数演化的"山脉"效果。
14. **核密度估计 KDE Contour** — 二维密度等高线。
15. **六边形分箱图 Hexbin** — 大数据量散点的密度替代。
16. **分位数-分位数图 QQ-Plot** — 检验分布假设（正态性等）。

### 3.3 构成占比类（Composition）

17. **饼图 Pie Chart** — 慎用；仅 2–4 类且序数不重要时可用；否则改用堆叠柱/华夫饼。
18. **南丁格尔玫瑰图 Nightingale Rose** — 扇形半径表数值；适合循环数据（24 小时、12 月）。
19. **旭日图 Sunburst** — 层级占比（组→子组→孙组）；交互式尤佳。
20. **矩形树图 Treemap** — 面积表占比的层级矩形；适合 10+ 类。
21. **堆叠面积图 Stacked Area** — 总量+构成随 x 演化。
22. **冲积图 Alluvial Diagram** — 类别成员在多个阶段间流动的构成变化（类似桑基但节点为类）。
    - 数学建模应用：**分档/状态迁移、不同轮次球队晋级结构变化**。

### 3.4 关系/相关性类（Relationship / Correlation）

23. **散点图 Scatter** — 基础；可叠加回归线、95% 置信带、相关系数 r 标注。
24. **边际图 Marginal Plots** — 主散点 + 顶部/右侧直方图或箱线（`scatter + hist` 组合）。
25. **气泡图 Bubble Chart** — 第 3 维编码到点面积；慎用（面积感知偏差），可配合标签。
26. **相关矩阵热图 Correlation Heatmap** — 色块编码 r；对角 1；可叠加显著性星号。
27. **聚类热图 Clustered Heatmap** — 行列层次聚类 + 热图；揭示样本/特征分块模式。
28. **PCA/因子双标图 Biplot** — 降维散点 + 载荷向量；高维样本聚类可视化。
29. **平行坐标图 Parallel Coordinates** — 每轴一变量、折线为样本；适合找多维模式与异常。
30. **弦图 Chord Diagram** — 圆形节点 + 弦表示双向流量；适合"谁与谁互动多少"。
    - 数学建模应用：**小组间晋级来源、区域间球队流动、网络拓扑**。
31. **网络图 Network Graph** — 节点-边布局；可选力导向/圆形；度、社区着色。
32. **UPset 图** — 集合交叠可视化的现代替代（替代韦恩图，>3 个集合时）。
33. **韦恩图 Venn** — ≤3 集交叠。

### 3.5 时序与趋势类（Time Series & Trend）

34. **折线图 Line Chart** — 多序列对比；标注转折点/事件；可用对数轴。
35. **置信带折线（均值±区间）** — 误差棒或置信带（`fill_between`）；多次随机实验均值±std/95%CI。
36. **阶梯图 Step Chart** — 离散跳变过程（库存、积分）。
37. **面积/堆叠面积图** — 见 3.3。
38. **流图 Streamgraph** — 有机形态堆叠面积；用于主题随时间构成演化。
39. **甘特图 Gantt Chart** — 任务/项目时间安排横条。
    - 数学建模应用：**赛程表（场馆-时段安排）、任务排程、算法各阶段耗时**——本题 P2 赛程非常适合用甘特图展示！
40. **时间线图 Timeline** — 事件沿轴标注（里程碑）。
41. **日历热图 Calendar Heatmap** — 一年/一月热力日历；周期性数据。
42. **季节性子图 Seasonal Subseries** — 按月/周分面拆趋势。
43. **自相关图 ACF/PACF** — 序列相关性诊断。
44. **收敛曲线 Convergence Plot** — 迭代/采样数 vs 目标值；对数轴更清晰。
    - 数学建模应用：**模拟退火收敛、蒙特卡洛 20000 次收敛性、损失下降**。

### 3.6 空间地理类（Spatial）

45. **分级统计图 Choropleth** — 面要素按值填充色阶。
46. **地理散点/符号图** — 点位数值大小符号。
47. **六边形/方形分箱地图** — 密度。
48. **等值线/等高线图 Contour** — 连续场（温度、地形）。
49. **连接线图 Map with Lines** — 起点-终点连线（航班、球队迁徙）。
    - 数学建模应用：**球队旅行线路图、场馆间距离网络**。
50. **网络距离矩阵图** — 距离矩阵热图/树状图。

### 3.7 流程、结构、网络类（Process / Structure）

51. **流程图 Flowchart** — 算法逻辑、模型技术路线；统一形状规范（起止=圆角矩形、判断=菱形、处理=矩形）。
52. **技术路线图/框架图 Framework Diagram** — 数据→特征→模型→结果的分层方框图（数学建模摘要/模型部分"门面图"）。
53. **桑基图 Sankey Diagram** — 流量守恒的流向宽条（宽度=量）。
    - 数学建模应用：**资金/资源分配流向、赛程各阶段观众流、多方案资金分配**。
54. **决策树示意图 Decision Tree** — 树形结构 + 叶节点统计。
55. **泳道图 Swimlane** — 按角色/部门的流程。
56. **因果图/贝叶斯网络图**。
57. **组织/层级结构图 Dendrogram** — 聚类树状图。

### 3.8 高维与多变量类（High-dimensional / Multivariate）

58. **分面网格 Facet Grid** — 按类别拆多个小子图（row×col）；适合 3–4 维。
59. **雷达图**（见 5）。
60. **平行坐标**（见 29）。
61. **热力图（矩阵）**（见 26/27）。
62. **PCA/TSNE/UMAP 2D 投影** — 高维聚类；标注贡献率方差。
63. **3D 曲面/散点图 3D Surface/Scatter** — 慎用：仅当需要真实第三维（参数曲面、损失面）时；旋转视角图提供多视角；多数场景用 2D 热图代替。
64. **等值线图**（见 48）。

### 3.9 不确定性与区间类（Uncertainty）

65. **误差棒 Error Bar** — 均值 ± SE/SD/CI（注明口径！）。
66. **置信带**（见 35）。
67. **误差椭圆 Confidence Ellipse** — 二元正态置信域。
68. **分位数带 Quantile Band** — 如 5%–95% 区间带。
69. **小提琴+箱线组合**（见 8/9）。
70. **热图+掩膜（mask）** — 不显著区域置灰。

### 3.10 叙事、复合与创新类（Narrative & Innovation）

71. **组合图 Combo Chart** — 柱+折线双轴（务必标注左右轴含义；不同量纲慎用，可用双图/双色避免误导）。
72. **标注图 Annotated Figure** — 用箭头/文字框/垂直线标注关键点、阈值、转折（"讲故事"）。
73. **小倍数 Small Multiples** — 同坐标多格对比，消除不同轴误导。
74. **华夫饼/icon 图 Icon Array** — 人形格代表人数（医疗叙事常用）。
75. **甘特+热力组合（赛程总览图）** — 每队每轮安排 = 热力/甘特矩阵；数学建模赛程题的"门面创新图"。
76. **动画/交互图（网页）** — 竞赛论文以静态为主，可在附录/支撑材料提供 GIF。
77. **信息图 Infographic** — 数模论文慎用大面积装饰，仅流程页适度使用。
78. **3D 打印/球面投影等** — 除非课题需要，不建议。
79. **"问题-方法-结论"三层封面示意图** — 论文摘要页可放一张总览示意图（创新形式：把整题流程画成一张语义图）。

### 3.11 双轴与多图融合（Dual-axis & Chart Fusion）

> "融合" = 在一张图里叠加/并列两种及以上图表类型，一个图回答多个视角（如"量 + 变化率"、"分布 + 趋势"、"排程 + 热度 + 重要性"）。它是最常见的"高级感"来源，但也最容易画错、最容易被评委质疑误导——**融合前先自问：两个视角是否真需要共享一张图？量纲与尺度是否可比？**

#### 3.11.1 双轴图（Dual-axis / Twin Axes）—— 第一原则：慎用

- 本质：两条 y 轴承载**不同量纲/不同尺度**的序列。
- 适用（可接受）：两序列**强相关叙事**（如 产值(柱,元) vs 增长率(线,%)、观众数(柱) vs 收视率(线)）且**必须同图对比趋势**时。
- 硬规则：
  1. 主轴/次轴**各自标注单位**（左轴：观看人数(百万)；右轴：增长率(%)）；
  2. 用**颜色/线型把序列与轴一一对应**，并在图例写清"对应左/右轴"；
  3. 两条序列在画面内的量程应让**曲线形状可比**（避免人为放大/缩小误导）；
  4. 柱（0 基线）与线（非 0 起点）叠加时最易误导——**优先拆成上下双面板**；
  5. 图注里写一句"左右轴量纲不同，仅比较趋势，勿直接比数值高低"。
- 替代方案（更稳妥）：**双面板小倍数**（两个子图共享 x 轴）、把变化率画成第二子图、或用百分比归一化后单轴。
- 给 LLM 的约束句：`若需双轴，请：(a) 两轴各标单位；(b) 序列-轴颜色一一对应；(c) 在图注声明量纲不可直接比较；若认为双轴会误导，请改为上下双面板共享x轴方案并说明理由。`

#### 3.11.2 多图融合的 13 个成熟模板（可直接套用）

| # | 融合形式 | 组成 | 典型场景 | 提示词要点 |
|---|---|---|---|---|

## 5. "图表创新"怎么做才加分

评委眼中的"创新图表"= **信息密度高 + 表达新颖且准确 + 与问题强相关**，而不是花哨：

1. **组合语义图**：把多个相关指标放进一张图（如"赛程总览=甘特×热力×重要性点"），并配局部放大/标注。
2. **"小倍数 + 统一坐标系"**：多个方案同轴对比，视觉公平（比单图叠很多线更专业）。
3. **概率与不确定可视化**：雨云图、置信带、ECDF——数学建模对"不确定性"的表达是加分项（比只画均值高大上）。
4. **针对性定制图**：为问题定制轴含义（如 P2 把"黄金时段/场馆容量"编码成点的大小或颜色，加在甘特图上）。
5. **把"比较"画成"变化"**：哑铃图、桑基/冲积图能讲"从 A 到 B 变了多少"的故事，比并列柱状更有洞察。
6. **用"正确的高级图"而非"堆量"**：一张雨云图的信息量 > 三张普通箱线；一张聚类热图 > 五张散点。
7. **图注讲故事**：每张图下 1–2 句结论式说明（"优化后旅行负担下降 38.6%，主要来自……"）。
8. **风格统一**：同一色板贯穿全文；矢量导出；公式符号与图内符号一致。

> 参考：国赛/美赛优秀论文插图拆解（[数学建模番外篇3：优秀论文插图整理&分析](https://cloud.tencent.cn/developer/article/2022416)、[番外篇4（2020）](https://cloud.tencent.cn/developer/article/2022418)）普遍是"**技术路线图 + 多子图分面 + 热力图/组合图 + 结论性图注**"的组合。

## 6. 论文版面美学与视觉叙事（Deep Paper Gestalt）

> 本节把视野从"**单张图怎么画**"提升到"**整篇论文怎么排版才像高水平论文**"。核心依据：
> - **[Deep Paper Gestalt（CVPR 2019）](https://ar5iv.labs.arxiv.org/html/1812.08775)**：把大量 CVPR/ICCV 投稿渲染成页面图像，用 74 维低层视觉特征（页面布局、图/表/文字比例与密度、格式一致性、视觉复杂度等）训练分类器，发现**仅凭"排版完形"就能以显著高于随机水平的准确率预测一篇论文是否被接收**——即"视觉结构与排版质量"本身就是评审印象的强信号。
> - **[IEEE VIS 2025 teaser 设计研究](https://chinavis.org/2025/papers/Teasers%20That%20Speak%20Exploring%20the%20Visual%20Design%20of%20Teaser%20Images%20in%20Visualization%20Publications.pdf)**：分析顶会首图的视觉设计维度（信息层级、视觉流畅路径、上下文支架等）。
> - **[格式塔理论在科技论文插图编校中的运用](http://dianda.cqvip.com/Qikan/Article/Detail?id=7107559251)**：接近性、相似性、闭合性等格式塔原则如何服务插图编校。

> ⚠️ 理解边界：Gestalt 类研究发现的是"**视觉质量与第一印象相关**"，不等于"包装胜过内容"。正确用法是：**内容与方法立得住的前提下，让排版不拖后腿、并放大已有亮点**——这是给 LLM 提示时的默认立场，也应在论文的 AI 声明中如实说明排版辅助用途。

### 6.1 从 Gestalt 结论提炼的 6 条"版面级"规律

1. **第一页就是产品页**：审稿人最先接触的是摘要页 + 首页版式；顶会论文首页往往在首屏放一张高信息量总览图（teaser），让读者 10 秒内建立"问题—方法—效果"的完形。数学建模论文虽摘要页通常不放图，但**问题分析/模型建立的开篇首图**承担同样的"抓眼"任务。
2. **视觉密度要"梯度化"**：Gestalt 分析中，纯文字页、全图页都会拉低观感；高质量论文的图/表/公式密度呈**节奏化分布**（每 0.5–1.5 页有一个视觉锚点），避免连续多页"字墙"。
3. **格式一致性是"可信度税"**：同一篇论文里字号、字体族、行距、公式编号、图表编号、图题格式、坐标风格不一致，会系统性拉低质量感知。把风格定义成"变量"，全篇复用。
4. **版面复杂度与"认真度"正相关，但过度装饰负相关**：适度信息密度（多子图、统一坐标系、清晰标注）显得专业；无意义的 3D、彩虹色、花哨阴影反而触发"业余感"。
5. **图表是结论的承载体，不是数据倾倒**：Gestalt 高分论文的图都"讲一句人话"（图题或图中标注给出比较/趋势/差异），而不是让读者自己找。
6. **留白与比例管理**：对齐、成组、留白（接近性/相似性/闭合性）决定读者视线路径；图内文字不要溢出、图与图题间距统一。

### 6.2 "单图规范 → 全篇版面"的提升清单

| 层面 | 单图级（已在前文覆盖） | 版面级（本节新增，提示 LLM 时也要带上） |
|---|---|---|
| 目标 | 一张图讲清一个结论 | 全文按"视觉脚本"安排每节 0–2 张锚点图 |
| 风格 | 该图颜色/字体自洽 | 全文共享同一套风格变量（色板名、字体名、线宽、字号、dpi、图宽） |
| 图号 | 图题完整 | 编号连续、正文"如图 N 所示"先于图出现 |
| 坐标 | 轴标签+单位 | 全篇单位制统一；同一物理量在全文用同一符号与单位 |
| 图注 | 结论式说明 | 每张图配"图题（结论）＋图注（方法/数据口径/n）" |
| 对比 | 图内对比 | 方案对比图成组出现（同坐标小倍数），便于跨图对照 |
| 首图 | —— | 开篇设"高视觉热度"总览/技术路线图（详见 6.4） |
| 表格 | —— | 大表格→热力图/分组条；文字描述→三线表；参数→表格统一三位数格式 |

### 6.3 数学建模论文的"全篇视觉脚本"（推荐节奏）

| 章节 | 视觉任务 | 建议放置的图/表（示例节奏） |
|---|---|---|
| 摘要页（1页） | 干净、信息完整 | 一般不放图（题目格式要求摘要≤1页），关键词收尾 |
| 一、问题重述 | 让读者"看见"问题 | 可放 1 张小示意图（赛制结构/对象系统）或用文字+编号 |
| 二、问题分析 | **第一视觉热区** | 图1 总览/数据驱动框架图：数据→特征→模型→约束→输出（门面图）；各问分析可配小图 |
| 三、假设 / 四、符号 | 结构化 | 假设编号列表；符号说明用三线表（两栏式省空间） |
| 五、模型建立与求解 | 每问 1–3 锚点图 | 每问：先技术细节（公式），后"结果图"（分布/相关性/拟合/对比/收敛/热力），再表格（关键数值） |
| 六、检验 | 证据感 | 收敛曲线、CV 误差对比、灵敏度多线图、误差/置信带 |
| 七、评价 | 收尾 | 优缺点结构化文本，可加 1 张"方案总览"雷达/哑铃图 |
| 附录 | 完整性 | 代码清单、支撑材料列表 |

> 节奏口诀：**"结论前置→证据图→关键数值表→过渡到下一问"**；避免任何一节连续 2 页无图/表/公式锚点。

### 6.4 开篇"高视觉热度"总览图（Teaser）设计配方

CVPR 式 teaser 的本质：**一图讲完"输入长什么样 + 我们怎么做 + 效果如何"**。数学建模中可用同样配方做"技术路线+结果摘要"复合图，放在问题分析开头或模型部分开头：

1. **三段式布局**（左→中→右，或上→中→下）：
   - 左/上：**输入与数据**（数据表缩略、分布/热力小图、问题结构示意）；
   - 中：**方法主干**（模型/约束/求解框，箭头串成流程，标关键公式号）；
   - 右/下：**结果锚点**（1–2 个核心指标对比条/曲线，如"Z2=…、MSE=…、改善 x%"）。
2. **信息密度**：一张图 3–6 个"视觉单元"为宜；每个单元可读不可拥挤；单元之间用箭头/泳道/分组框建立阅读顺序。
3. **统一风格**：整图一个色板（1 个主色 + 1 个强调色 + 灰），同类对象同形同色；字号 9–11pt 可打印。
4. **图题写结论**：如"图1 数据驱动的赛程决策框架与关键结果（优化后综合目标 Z2=…）"。
5. **实现提示**：先给 LLM 该配方 + 你的数据文件/结果数值，请它输出分块草图（用注释描述每块内容）→ 再落成代码；不要让它一次生成含真实数据的巨图再返工。

### 6.5 LLM "论文级"提示模板（把整篇论文当视觉产品）

```
你是学术排版与可视化总监，熟读 Deep Paper Gestalt（CVPR 2019）与顶会 teaser 设计规范。
我将给你一篇数学建模论文的章节提纲与各章拟呈现的结果（数值/表/文件路径）。

请输出一份"全篇视觉方案"（先方案后代码）：
1. 视觉脚本表：每章 [章节名] → 锚点图/表 [图型+一句结论式图题] → 该图数据来源；
2. 风格系统：统一色板（给 hex）、字体（中/英）、线宽、字号、图宽、dpi、图题格式——全文一份；
3. 开篇总览图（teaser）设计：三段式草图描述 + 布局建议 + 需要我提供哪些数值；
4. 逐图代码（用 <MATLAB/Python>）：每图一段，遵循第 3 步风格系统；复杂图先给"单元划分注释"；
5. 输出自查：图号连续？单位统一？每图图题是否结论化？有无连续"字墙"章节？
约束：不使用统计/ML工具箱以外的依赖；中文标签用宋体，数字英文用 Times/Helvetica；矢量+300dpi。
我的章节提纲与结果：
<粘贴提纲、关键数值、结果文件说明>
```

## 7. 配色、字体、尺寸与排版规范

### 7.1 配色（学术级）

| 色板 | 用途 | 推荐 |
|---|---|---|
| Okabe-Ito / Tableau10 / tab20 | 类别色（首选，色盲安全） | 类别 ≤10 用 Okabe-Ito |
| Viridis / Plasma / Cividis | 连续色阶（热图） | Cividis 色盲友好 |
| RdBu / RdYlBu 等 diverging | 正负双向（相关热图） | 中间设中性色 |
| Nature/Science 风格（黑灰+单强调色） | 正式期刊 | 论文全篇 1–2 个强调色即可 |

- 色盲安全检测建议用 Colorgorical / `colorblind` 校验；参考 [Accessible Color Sequences](https://ar5iv.labs.arxiv.org/html/2107.02270)、[Scientific Color Lab](https://raw.githubusercontent.com/groele/Scientific-Color-Lab/main/README.md)。
- 禁用：rainbow/jet 连续色（感知不均、色盲不友好）、大红大绿并列。


**配色可复制细节（给 LLM 时直接粘贴）**

- Okabe-Ito（类别 ≤8，色盲安全）：`#000000 #E69F00 #56B4E9 #009E73 #F0E442 #0072B2 #D55E00 #CC79A7`
- matplotlib tab10（数据探索常用）：`#1f77b4 #ff7f0e #2ca02c #d62728 #9467bd #8c564b #e377c2 #7f7f7f #bcbd22 #17becf`
- 连续色阶：Viridis 采样 `#440154 #3b528b #21918c #5ec962 #fde725`；Cividis（色盲友好）`#00204d #2c4875 #8b7a6c #fdfde8`（或直接用库内 cividis）
- 发散色阶（相关/差异）：RdBu `#b2182b(负) → #f7f7f7(0) → #2166ac(正)`
- Nature/Science 极简：主体黑 `#000000` + 强调橙 `#E69F00` 或 蓝 `#0072B2` + 灰 `#808080`；或蓝 `#4C72B0`+红 `#C44E52`（seaborn deep）
- 单色深浅梯度（避免>8 类时色相爆炸）：同一 `#0072B2` 按明度 0.15–0.85 生成 10 档

**语义色映射速查（常见对比对，选其一并全篇统一）**

| 对比含义 | 推荐色对 | 备注 |
|---|---|---|
| 方案A vs B / 实际 vs 优化 | `#0072B2(蓝)` vs `#D55E00(橙)` | 最不易混淆的一对 |
| 预测 vs 真实 | 真实=`#000000` 实线，预测=`#D55E00` 虚线 | 线型区分优先于颜色 |
| 正 vs 负 | `#D55E00` vs `#0072B2`（或 RdBu） | 不用红-绿 |
| 主 vs 次轴（双轴） | 主轴黑/主色，次轴同色但虚线或浅灰 | 图例写清轴归属 |
| 分组 1..k（k>6） | 同色相明度梯度 或 分面 | 不用彩虹 |

**给 LLM 的配色提示词模板（直接复制）**

```
配色要求：
1) 类别色使用 Okabe-Ito（色盲安全）：#000000 #E69F00 #56B4E9 #009E73 #F0E442 #0072B2 #D55E00 #CC79A7；如需更多类，改用同一色相的明度梯度，不要引入新色相；
2) 连续色阶用 <viridis/cividis/单蓝>，不要用 rainbow/jet；发散用 RdBu，0 值须为近白中性色；
3) 禁止红绿并用做语义正反对（色盲）；对比对优先 蓝#0072B2 vs 橙#D55E00；
4) 双轴图：两序列颜色与左右轴一一对应，并在图例注明"对应左/右轴"；
5) 背景纯白、去上右框线、网格浅灰(#E0E0E0)虚线；

```

### 7.2 字体与字号

- 中文正文宋体/标题黑体；图内文字建议 **Helvetica/Arial 或 Times**（与论文一致），字号 7–9 pt（出版级）、竞赛可 9–11 pt。
- 轴标签、图例、刻度字号协调：刻度 < 轴标签 < 图题。
- MATLAB：`set(gca,'FontName','Helvetica','FontSize',10)`；导出 `exportgraphics(gcf,'f.png','Resolution',300)`。

### 7.3 尺寸与格式

- 单栏图宽 3.2–3.5 in，双栏 6.5–7 in；高宽比一般 3:4 或 4:3。
- 导出 **矢量 PDF/SVG**（论文插图首选）；位图 ≥300 dpi（PNG/TIFF）。
- 多子图用统一坐标系与色标（共享 colorbar 标注范围）。
- 坐标轴单位括号规范："观看人数 (百万人)"；数字刻度 3 位分组。

### 7.4 布局检查清单（出图前过一遍）

- [ ] 轴有标签与单位？ [ ] 图例覆盖全部系列且不遮挡数据？
- [ ] 色盲可辨？ [ ] 字体缩到打印尺寸仍可读？ [ ] 离群/异常有解释？
- [ ] 统计口径（均值/中位数、SD/SE/CI、n）在正文或图注声明？ [ ] 矢量/300dpi？
