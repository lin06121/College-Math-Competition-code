# 问题 3 —— 多预报时刻滚动调整购电策略：算法与结果

> 目标：在电价（附件 1）、实际负载与光伏（附件 2）、光伏预报（附件 3）已知的条件下，
> 制定 0:00 计划购电量 + 6:00/12:00/18:00 调整购电量 + 实时执行的完整策略，使全年
> 总费用最小；产出 `result3.xlsx` 与论文表 1/2/3，并回答"是否需要引入其他时刻预报"。
> 求解窗口 **2025-02-01 ~ 2025-12-31（334 天）**，储能从 2025-01-01 0:00 的 6000 kWh 起逐日滚动。

---

## 1. 问题理解与信息结构

与问题 2 的唯一本质差别是**信息随时间变丰富**：附件 3 每天 0:00 / 6:00 / 12:00 / 18:00
发布未来 24 小时整点光伏预报。因此除 0:00 的计划购电量 `P_plan`，还能在当天多次
**调整** `P_adj`，并对两者偏差按惩罚电价结算。负载没有给定预报，仍沿用问题 2 的
历史预测方法（只能使用当天之前的数据）。

**附件 3 对齐规则**（经数据验证；本文曾误用阶梯插值，已修正）：

`预报k小时` 是发布时刻之后**第 k 个整点（发布时刻 + k 小时）的瞬时功率**，
**不是**该小时的平均功率。在 10 分钟网格上，第 k 个整点对应时段
`s0 + k·6 − 1`（即结束于该整点的那个 10 分钟时段），相邻整点之间**线性插值**：

| 发布时刻 | s0 | 预报 k 小时对应时段 |
|---|---|---|
| 0:00 | 0 | `k·6 − 1` |
| 6:00 | 36 | `36 + k·6 − 1` |
| 12:00 | 72 | `72 + k·6 − 1` |
| 18:00 | 108 | `108 + k·6 − 1` |

发布时刻本身不在 24 个整点之列（首个整点在 +1 小时处），故 `[s0, s0+1h)` 缺左端点。
用**上一期预报的「预报 6 小时」**（恰为当前发布时刻那个整点）补上 `s0−1` 处的锚点，
首小时即可正常插值；0:00 期用前一日 18:00 期。补齐锚点后各期 MAE 进一步下降
（6:00 期 185.8 → 158.6，18:00 期 19.4 → 10.1）。

**验证依据**：对四个发布时刻分别扫描偏移 `off ∈ [−6, +12]`，即
`预报k小时 ↔ slot s0+(k−1)·6+off`，MAE 均在 **off = +5** 取最小（四期一致），
整点瞬时值假设由此确认。该检验已固化为 `run_q3.py::check_alignment` 回归测试。

超出当日 24:00 的预报属次日，置 NaN（问题 3 只调整当日剩余时段）。

## 2. 附件 3 预报误差 vs 问题 2 平均法误差

2025-02-01 ~ 12-31，**同一时段区间**下比较（修正对齐后）：

| 发布时刻 | 区间 | 附件 3 MAE | bias | 问题 2 最近 4 日平均（同区间） | 附件 3 operational |
|---|---|---|---|---|---|
| 0:00 | slot 0+ | 197.5 | −29.7 | **152.0** | 94.3 |
| 6:00 | slot 36+ | **158.6** | −13.5 | 201.5 | 122.2 |
| 12:00 | slot 72+ | **80.8** | +1.3 | 146.9 | 89.7 |
| 18:00 | slot 108+ | 10.1 | +10.0 | 2.0 | 10.1 |

**结论：附件 3 预报整体优于问题 2 的历史平均法。**

1. 12:00 期（80.8 vs 146.9）与 6:00 期（158.6 vs 201.5）都明显更准；
2. 只有 **0:00 期略逊**（197.5 vs 152.0）——它要预报未来 24 小时（lead 1–24 h），
   是所有期里最差的；
3. 18:00 期覆盖的 slot 108+ 基本是夜间（光伏 ≈ 0），两者绝对误差都很小。

**这同时解释了两件事**：① 问题 3 的日前计划被迫绑在最差的 0:00 期上，所以
slot 0–35 那一小段信息最弱；② 越晚的发布时刻预报越准（197.5 → 158.6 → 80.8 → 10.1），
**这正是滚动调整的价值来源**。

> **勘误（重要）**：本文早期版本曾报告"附件 3 的 0:00 期 MAE 371 kW、12:00 期系统性
> 低估 267 kW，均差于平均法 152 kW，故必须去偏才能翻盘"。该结论**是阶梯插值错位造出
> 的假象**——把整点瞬时值摊到整个小时，在中午光伏每小时变化可达 800 kW 时凭空造出
> 数百 kW 误差（12:00 期 −267 kW 的"偏差"几乎全部来自此）。修正对齐后四期 MAE 降至
> 197.5 / 158.6 / 80.8 / 10.1，偏差缩到 −30~+10 kW，"附件 3 更差"不成立。

### 2.1 预报偏差校正：评估过，**未采用**

修正对齐后各期仍有小幅系统偏差（−29.7 / −13.5 / +1.3 / +10.0 kW）。
`forecast_q3.debias_forecast_matrix` 可用**目标日之前** 20 天内已实现的预报误差
均值做因果校正：

```
bias(k,a,t) = mean( fc(j,a,t) − pv_actual(j,t) ) ,  j ∈ [k−20, k−1]
去偏预报     = fc(k,a,t) − bias(k,a,t)
```

微网自有光伏出力与收到的预报都是它可观测的信息，故该修正在线可实施，不用任何未来信息。

| 全年 2025-02-01 ~ 12-31（q=0.6, λ=0.45） | 总费用（元） | 紧急电量（kWh） |
|---|---|---|
| **直接用附件 3 预报（采用）** | **13,383,402** | 78,211 |
| 附加因果去偏 | 13,321,760 | 67,900 |

去偏仅再省 61,643 元（**0.46%**），却要多一层后处理；且 1 月标定窗口看不出收益
（仅差 432 元）。**故主模型不采用**，`debias_forecast_matrix` 保留为可选工具
（`debias=True` 即启用），论文中可作为"预报后处理"的敏感性分析。

> **读法建议**：主结论**不依赖**去偏——附件 3 预报本身已优于问题 2 的平均法（见 §2），
> 直接使用附件 3 也更贴近题意。

> **与 EDA 报告的口径对齐**：报告中的 MAE 161.8 kW、MBE −10.9 kW、RMSE 246.8 kW 是
> **白天（实际光伏 > 0）** 的 operational 误差，本文已精确复现（161.76 / −10.85 /
> 246.79）；跨全部 144 时段（含夜间零值）的同一预报 MAE 为 91.75 kW。报告"1 小时
> MAE ≈ 35 kW、6 小时 250–300 kW"一句与数据不符：逐 10 分钟白天口径为 1–2 h
> 109 kW、6–7 h 229 kW（这些分桶的均值恰好回落到 161.8，故 headline 正确、该句有误）。

## 3. 结算口径（题面字面读法）

对每个时段 t（c 为当时电价，Δt = 1/6 h）：

```
费用(t) = c·P_adj
        + 0.5·c·(P_plan − P_adj)₊     # 计划高于调整：少买部分按当时电价 50% 计违约
        + 0.5·c·(P_adj − P_plan)₊     # 调整高于计划：多买部分总价 1.5 倍
        + 5·c·P_em                     # 紧急购电 5 倍
      = c·P_adj + 0.5·c·|P_adj − P_plan| + 5·c·P_em
```

即**只按实际购入量 P_adj 付全价**，偏差部分少买 0.5c、多买 1.5c，两句题面同时成立；
计划量本身不预付。由该式，调整 LP 的目标（去掉常数项）为

```
min Σ [ 1.5·c·P_pos − 0.5·c·P_neg ]·Δt ,   P_adj = P_plan + P_pos − P_neg
```

`P_neg` 系数为 **−0.5c**：字面口径下"少买一节电"净省 0.5c，因此模型会把储能优先
配置到高价时段压低购电量。这是该口径的真实经济含义，全年少买 669,164 kWh、
违约费 200,821 元，占总费用 1.5%，量级可控。

## 4. 算法总体流程

```
E ← 6000 kWh
for 每天 d = 2025-01-01 … 2025-12-31:
    # ── 0:00 计划 ──
    load_f  = 最近 4 个同类日（周五/六 vs 其余）负载均值
    margin  = 净负载残差的 q 分位（报童裕度，q 在 1 月标定）
    P_plan  = MILP(price, load_f+margin, pv_debias[d, 0:00], E)     # 全天 144 时段
    P_adj   = P_plan
    # ── 分段：调整 → 执行 ──
    boundaries = [0, 36, 72, 108, 144]
    for k, 发布时刻 s ∈ {0:00, 6:00, 12:00, 18:00}:
        if s > 0:
            P_adj[s:] = 调整MILP(price, load_f+margin − pv_debias[d,s], P_plan, E_实际(s))
            # 基准恒为 0:00 的 P_plan，不是上一阶段解
        # 用实际负载/光伏对该段做因果结算
        P_ch,P_dis,P_em,P_curt, E_seg ← causal_dispatch(实际净负载[s:e], P_adj[s:e], E_实际(s))
        E_实际 ← E_seg[-1]
    E ← E_实际(144)
```

要点：
- **调整基准恒为 0:00 的 P_plan**（题面"计划购电量"），而非上一阶段结果；
- 每次调整用该时刻**最新**的光伏预报与该时刻**实测**的储电量起步；
- 各阶段只影响 `P_adj[s:]`，早于 s 的时段不再改动（非预期性）；
- 实际执行始终是**因果**规则，只用当前时段实测，不使用未来实测。

## 5. 调整阶段 MILP

变量 `P_pos, P_neg, P_ch, P_dis, P_curt, E, u`（u 为充放电 0-1 变量）：

```
min   Σ [ 1.5·c·P_pos − 0.5·c·P_neg ]·Δt
s.t.  P_pos − P_neg − P_ch + P_dis − P_curt = net_f − P_plan     (功率平衡)
      E(j+1) = E(j) + η·P_ch·Δt − P_dis/η·Δt                     (储能动态)
      E(start) = 该时刻实测储电量
      1200 ≤ E ≤ 10800 ,  0 ≤ P_ch, P_dis ≤ 5000
      P_ch ≤ 5000·u ,  P_dis ≤ 5000·(1−u)                        (充放电互斥)
      0 ≤ P_adj = P_plan + P_pos − P_neg ≤ 20000
```

`net_f = load_f + margin − pv_fc[s]`（`pv_fc[s]` 为该发布时刻的光伏预报）。
LP 恒可行（`P_pos` 无上界可吸收缺额，
`P_curt` 吸收富余；电池取零充放即可行）。

## 6. 联合标定：报童分位 q 与终端储能价值 λ

两个参数都在 **2025-01-08 ~ 01-31** 上联合网格搜索（`q ∈ {0.4…0.9}` ×
`λ ∈ {0, 0.3, 0.4, 0.45, 0.5}`），2–12 月为外样本，口径与选址完全一致。

```
min Σ [ c·P_adj + 0.5c·|P_adj − P_plan| + 5c·P_em ]·Δt  −  λ·E(144)
```

**标定结果 q\* = 0.60，λ\* = 0.45**（元/kWh）。

### 6.1 为什么需要 λ，且它必须标定

λ 是日终储电量 E(144) 的影子价格。不设该项（λ=0）时，日终剩余电量对当日目标没有任何
价值，优化会把它榨干——本模型 334 天里有 **39 天把储电量放到 1200 kWh 的下限**，
日终 SOC 中位数仅 1425 kWh。这正是滚动时域里典型的"日终放空"短视行为。

但 λ **不能随手取大**，因为目标里 `−λ·E(144)` 是线性的、最优解会落在边界上，
形成**开关行为**。全年扫描（q=0.6）：

| λ | 0.41 | 0.42 | **0.43–0.46** | 0.47 | 0.48 | 0.49 | 0.50–0.80 |
|---|---|---|---|---|---|---|---|
| 总费用（元） | 13,419,209 | 13,419,209 | **13,383,402~13,383,891** | 13,384,854 | 13,440,683 | 13,484,823 | 13,485,677 |
| e_end 中位 | 1,425 | 1,425 | **2,148** | 5,109 | 10,232 | 10,800 | 10,800 |
| 贴底天数 | 39 | 39 | **6** | 0 | 0 | 0 | 0 |
| 贴顶天数 | 0 | 0 | **0** | 0 | 20 | 198 | 203 |
| 弃光（kWh） | 1,443,819 | 1,443,819 | **1,448,045** | 1,464,676 | 1,529,758 | 1,590,394 | 1,591,566 |

- **阈值 ≈ 0.425**：低于它终端价值根本不绑（λ ≤ 0.42 与 λ=0 结果几乎相同）；
- **[0.43, 0.46] 是稳定平台**（四档总费用只差 489 元），是本模型的正确取值区间；
- **λ ≥ 0.47 迅速恶化并饱和**：0.50 起 200+ 天把储电量顶到 10800 上限，弃光增 10%，
  总费用反而比 λ=0 **贵 66,522 元（+0.50%）**。

取 **λ = 0.45** 全年省 **35,752 元（0.27%）**，紧急购电量 94,041 → 78,211 kWh（−17%），
贴底天数 39 → 6。

> **对照**：同类解法中常见的取法是 `λ = η·日均电价 = 0.9×0.766 = 0.69`。该值在本模型
> 里**恰好落在病态区**（贴顶 203 天，比不做终端价值还贵 0.50%）——说明"要不要加终端
> 价值"远不如"**取值落在哪"关键，必须标定而非套用经验公式。

### 6.2 q 的敏感性

全年 q=0.6 → 13,383,402 元（λ=0.45 下）；λ=0 时 q=0.6/0.65/0.7 分别 13,419,155 /
13,405,622 / 13,443,004，故 q 不敏感（±0.3%）。修正对齐后预报变准，所需安全裕度比
问题 2 的 0.8 明显下降。

## 12. 假设与局限

1. **结算口径按题面字面读法**；若采用"计划量照付 + 偏差加罚"（take-or-pay）口径，
   目标中 `P_neg` 系数应改为 +0.5c（`_adjustment_lp` 已参数化 `under_coef/over_coef`）。
2. 负载在调整时刻**不重新预测**（题目只给光伏预报）；已观测的当日负载未用于修正
   剩余时段，可作为后续扩展。
3. 0:00 计划为确定性 MILP + 报童裕度（与问题 2 一致），未对调整阶段做两阶段随机
   规划的联合优化；后者是可选的理论延伸。
4. **附件 3 插值方式曾出错并已修正**（见 §1/§2 勘误）：早期版本按"小时平均值"做阶梯
   插值，实为"整点瞬时值"，导致 MAE 虚高（0:00 期 371→197 kW、12:00 期 286→81 kW）
   并误判预报质量。修正后已加 `check_alignment` 回归测试防止复发。
5. **预报去偏已评估但未采用**（见 §2.1）：全年仅再省 0.46%，且需多一层后处理；
   主模型直接使用附件 3 预报。若需启用，`solve_problem3(debias=True)` 即可。
6. 计划与调整均含终端储能价值 **λ = 0.45 元/kWh**（与 q 在 1 月联合标定；见 §6）。
   λ 过小则日终放空，过大则退化为"日终充满"的病态解，故必须标定。
7. 未考虑购电功率上限与并网约束（题目未给）。
8. 曾评估"日前阶段用 0.5×去偏0:00 + 0.5×4 日平均"的融合预报：1 月仅再省 0.5%，
   且与纯 4 日平均几乎无差，收益不显著，故未纳入主模型。
